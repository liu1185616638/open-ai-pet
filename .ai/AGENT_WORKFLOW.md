# Agent Workflow

## Step 1 - Understand

Read:

- AGENTS.md
- Current status
- Related design documents

## Step 2 - Plan

Before coding explain:

- implementation approach
- affected modules
- possible risks

## Step 3 - Implement

Rules:

- minimal changes
- preserve architecture
- avoid unrelated refactoring

## Step 4 - Validate

Perform appropriate:

- build check
- type check
- runtime verification
- tests

## Step 5 - Handoff

Update:

- CURRENT_STATUS.md
- DEVELOPMENT_LOG.md
- CHANGELOG.md
- DECISIONS.md when needed

The next agent should be able to continue without needing previous conversation history.
