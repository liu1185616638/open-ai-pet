# AI-Pet Project Overview

## Vision

AI-Pet is a desktop AI companion platform. It combines classic desktop pets, AI assistants and system awareness into a persistent digital life form.

## Product Features

- Transparent desktop pet
- Replaceable characters
- Working/resting/overclock states
- Random interactive events
- Click conversations
- AI model configuration
- Token based pet food system
- Future plugin ecosystem

## Target Experience

Similar to:

- QQ Pet
- Character AI
- Desktop AI Assistant
- Personal Agent

but focused on long-term companionship.

## MVP Goal

Version 0.1:

1. Desktop pet window
2. Animation state engine
3. Click interaction
4. Speech bubble
5. Basic pet state

Future:

- AI conversation
- Memory
- Pet marketplace
- Plugin SDK
