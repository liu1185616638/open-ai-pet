# Phase Completion Rules

A phase is complete only when:

1. Code implementation exists.
2. Acceptance criteria are met.
3. Related documentation is updated.
4. DEVELOPMENT_LOG.md is updated.
5. CURRENT_STATUS.md points to the next phase.

---

# Agent Continuation Rule

Agents must not skip phases unless DECISIONS.md records the reason.

Each Agent should:

1. Read AGENTS.md.
2. Read CURRENT_STATUS.md.
3. Read the current PHASE document.
4. Implement the smallest valid change.
5. Leave context for the next Agent.
