# Phase 1 Engineering Initialization

## Goal

Create a runnable Electron desktop application foundation.

## Tasks

### TASK-1.1 Electron Project

Implement:

- Electron
- Vite
- React
- TypeScript

Acceptance:

npm run dev starts successfully.

---

### TASK-1.2 Window System

Implement:

- Transparent window
- Frameless window
- Always on top
- Desktop pet container

Acceptance:

A transparent desktop window is visible.

---

### TASK-1.3 IPC Communication

Create safe communication between main and renderer processes.

Acceptance:

Shared IPC contracts exist.

---

### TASK-1.4 PixiJS Rendering

Implement base AnimationEngine integration.

Support:

- idle
- walk
- sleep

---

### TASK-1.5 Default Pet Loading

Load default pet package from pets/default-pet.

Acceptance:

Default pet appears in the desktop window.
